Exet tests: run everything

Runs each automated test page in a frame (with ?autorun) and collects the results here. Every page uses an in-memory localStorage, so your real crosswords are not touched. Serve this folder over http (or open the files directly): the pages report back using postMessage, which works for file:// pages too. Add ?autorun to this page's URL to start the run on load.
